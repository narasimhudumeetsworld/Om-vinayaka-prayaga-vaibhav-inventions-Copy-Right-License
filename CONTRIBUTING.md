## Contribution Process

### 1. Issue Creation
- Use GitHub Issues to propose changes
- Clearly describe the improvement or correction needed
- Reference specific files and line numbers when applicable
- Wait for approval before proceeding with implementation

### 2. Pull Request Guidelines
- Fork the repository (if permitted)
- Create a descriptive branch name: `improvement/description-of-change`
- Make minimal, focused changes
- Include detailed commit messages
- Reference the related issue number

### 3. Review Process
- All contributions require approval from Prayaga Vaibhav
- Legal review may be required for substantial changes
- Contributors may be asked to provide additional documentation
- Final approval authority rests with the copyright holder
